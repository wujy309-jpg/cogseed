## 4. 本地预览

在本设计包运行：

```sh
node tools/preview.cjs --port 4174
```

访问本机 `http://127.0.0.1:4174/`。复用已有 esbuild 环境，可通过 `COGSEED_ESBUILD_PATH` 指定。JSX 是设计预览源码，浏览器加载构建生成的 JS，不接入真实后台。

## 5. 交付检查

- 规范、组件卡片和页面使用同一套开源 token 与品牌资源。
- 页面默认展示不再使用专属字标、业务版徽标或企业专属默认场景；历史文件名与记录保持可追溯。
- 按影响范围检查默认、悬停、焦点、禁用、加载、错误与空状态。
- 检查入口直达、刷新、跳转、菜单 Escape 与焦点返回；不以离线契约检查替代浏览器证据。
- 分别陈述设计调整、生成结果、浏览器检查、待用户确认和未验证项。

正式客户端接入是后续独立任务。只有用户明确要求实施客户端时，才进入对应源码仓，重新核对分支、共享组件契约、业务保留点和运行验证要求。
