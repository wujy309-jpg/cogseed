## 1. 会议 #2 结论（目标结构）

**智能体页**展示三类：

| 类别 | 内容 | 使用方式 |
|---|---|---|
| 主智能体 | cogseed | 直接用 |
| 外接智能体 | Codex / Claude Code 等 | 保持现状，不动 |
| 平台 | Hub 分发 + 客户端内置，**合并，不再区分来源** | 内置直接用；Hub 的需先安装 |

- **我的智能体**：只放用户自己创建的；旁边有「贡献」按钮（技能同理）。
- **管理**：用户从 Hub 装下来的内容，做卸载 / 启用 / 停用；已安装排前面。如果能「一步直接用」，管理页就不需要了。
- **「N 万人在用」本期不展示**，只采集数据。
