## 1. 一句话目标

**用户打开"智能体"和"技能"页，就能看到所有可以用的东西，点一下就能用；不需要知道东西从哪来，也不需要理解内部结构。自己的东西在"我的"，从平台装的在"已安装"，每样东西只在一个地方管理。**

---

## 2. 术语

| 术语 | 含义 |
|---|---|
| 主智能体 | cogseed，用户默认对话的智能体，负责理解目标、拆解任务、调用其他智能体和技能 |
| 外接智能体 | 接入本机已有工具的智能体，如 Codex、Claude Code；是产品特色，单独一组 |
| 平台内容 | 由 Hub 平台分发的智能体和技能。**本期起，所有平台内容都来自 Hub**，不再有"客户端自带"这一类 |
| 安装 | 把平台内容下载到本机，并做质量与安全检查、登记。智能体和技能都在用户电脑上运行，所以第一次用之前必须安装 |
| 已安装 | 已经装到本机的平台内容，包括用户自己装的、老用户升级时从原随包内容迁移过来的 |
| 自建 / 自定义 | 用户在 CogSeed 里自己创建的智能体或技能，可以贡献到平台 |
| 本机已有的技能 | CogSeed 在用户电脑上读到的技能，分两种：**外部包**（通过 CogSeed 安装器装的第三方仓库，可能含命令行工具，以"包"为单位管理）和**全局文件夹**（`~/.claude/skills`、`~/.codex/skills` 里的技能，CogSeed 只读不改） |
| 系统内置技能 | 8 个产品自用的规程技能（如创建智能体、创建技能），不进商店，**不在页面上出现**，不受本期影响 |
| 连接器 | 另一类能力，必须内置在客户端，不走 Hub，不在本期范围 |
| 停用 | 用户关掉某个智能体或技能：主智能体在新任务里不再调用它，@ 也找不到它；可随时启用 |
| 卸载 | 把已安装的平台内容从本机移除；需要时可再安装 |

## 3. 页面结构

```
智能体页
├─ 首页
│   ├─ 主智能体：cogseed                         → 使用
│   ├─ 外接智能体：Codex、Claude Code 等          → 使用
│   └─ 平台：全部 Hub 内容，不标来源
│        ├─ 已安装的（排在前面）                  → 使用
│        └─ 未安装的（排在后面）                  → 安装（装好后变"使用"）
│   工具栏：分类 · 搜索 · [我的智能体 · N] · [已安装的智能体 · N]
├─ 我的智能体：只放自己创建的                      → 使用 / 贡献
│   工具栏：搜索 · [+ 创建] · [我的贡献]
└─ 已安装的智能体：从平台装的                      → 停用开关 / 卸载

技能页
├─ 首页
│   └─ 平台：同上（没有主智能体、外接两组）
│   工具栏：分类 · 搜索 · [我的技能 · N] · [已安装的技能 · N]
├─ 我的技能：自定义 + 本机已有（一个网格，按"全部 / 自定义 / 本机已有"筛选）
│   顶部：全局文件夹总开关；工具栏：搜索 · [+ 创建] · [我的贡献]
└─ 已安装的技能：从平台装的                        → 停用开关 / 卸载
```

点任何卡片都打开**同一种详情弹窗**（见 R2）。

**每样东西放在哪**

| 来源 | 首页 | 我的 | 已安装 |
|---|---|---|---|
| 主智能体 | ✓ | | |
| 外接智能体 | ✓ | | |
| 平台内容（已装 / 未装） | ✓ | | 已装的 ✓ |
| 自建 | | ✓ | |
| 本机已有的技能 | | ✓ | |

平台内容在首页和"已安装"都出现是有意的：首页是"所有能用的"，在那里使用；"已安装"是"我装过哪些"，在那里停用、卸载。

## 4. 主流程

**A. 发现并使用**：进入智能体页 → 在三组里找到想要的 → 点卡片打开详情，看它能做什么和示例 → 已安装的点"使用"进入新任务；点示例直接把这句话发出去。

**B. 安装**：未安装的卡片按钮是"安装" → 点了变"安装中…" → 装好后提示已安装，按钮变"使用"，页面不跳走。在详情里直接点示例，则先安装、装好后直接进入新任务并发送示例，一步完成。

**C. 停用与卸载**：首页工具栏"已安装的智能体 · N" → 列出所有装到本机的平台内容 → 每行拨开关停用 / 启用，或点"卸载"。

**D. 我的**：工具栏"我的智能体 · N" → 只看到自己创建的 → 可使用、贡献到平台、点开详情进入现有编辑工作台、停用；"我的贡献"查看提交与审核进度。"我的技能"里还有本机已有的技能：在详情里停用；外部包可在详情里"移除"；顶部总开关可整体不读全局文件夹。

**E. 创建**：在"我的"页点"+ 创建" → 选"创建"或"外接" → 填写名称、简介等 → 创建的出现在"我的"；外接的出现在首页"外接智能体"组。

## 5. 产品规则

| 编号 | 规则 | 理由 |
|---|---|---|
| R1 | **首页分组**：智能体页分"主智能体 / 外接智能体 / 平台"三组；技能页只有"平台"一组。平台组列出全部 Hub 内容，**不标来源**，已安装的在前、未安装的在后。首页不出现自建、本机已有的技能和系统内置技能 | 用户不需要知道内容从哪来，只需要知道有哪些能用 |
| R2 | **统一详情弹窗**：所有类型同一种弹窗。标题栏是图标 + 名称 + 说明行（分类 · 来源类别 · 版本）+ 关闭；正文依次为简介、标签、"智能体帮你做"示例（整行按钮，点一下就发送）、会用到的技能（标明是否就绪；智能体才有）、能做什么（技能才有）；操作在底部。**不展示内部结构**（工作流程原文、schema 等）。底部按钮：主按钮"使用"（未安装为"安装智能体 / 安装技能"）；主智能体只有"使用"；外接另有"管理 / 停用"；自建另有"贡献 / 管理 / 停用"；已安装的平台内容另有"停用 / 卸载"（有新版本时另有"更新"）；外部包技能另有"停用 / 移除"；全局文件夹技能另有"停用" | 同一概念不做两套详情 |
| R3 | **使用**：点"使用"或示例，进入客户端现有的新任务流程并选中该智能体 / 技能（本期不改新任务页）；点示例即发送这句话 | 用户想用时一步到位 |
| R4 | **断网 / 平台不可用**：首页顶部提示"暂时无法获取平台内容"和"重试"；平台组只显示已安装的，照常可用；"我的""已安装"不受影响。**不做离线兜底**（不在安装包里留备用清单）。**未登录**：主智能体、外接、我的、已安装照常可用；平台组只显示已安装的，并提示"登录后查看更多平台内容"；点"安装""贡献"时先提示登录 | 产品本身需要联网使用；服务器故障属运维范畴，客户端不额外设计。参考：WorkBuddy 断网后专家、技能列表也是空的 |
| R5 | **创建**：入口只在"我的"页工具栏；沿用现有"创建 / 外接"两种方式和校验（名称必填、字符限制、保留名、重名）；创建的进"我的"，外接的进首页"外接智能体" | 创建的东西都落在"我的"，入口跟着放在"我的" |
| R6 | **分类与搜索**：首页和"我的"都有搜索；首页、"我的智能体"有分类，分类沿用内容自带的分类字段；"我的技能"用来源筛选代替分类；搜索支持中文输入法，输入过程中不打断、不丢焦点 | — |
| R7 | **不展示"N 人在用"**：本期只采集数据，不展示（口径见 D-08）。标签为可选字段，有就显示 | 现阶段用户量小，数字没有代表性 |
| R8 | **安装**：未安装的只有"安装"一个按钮；点击后"安装中…"（不可重复点），装好后留在原处、按钮变"使用"（类似豆包"召唤"→"对话"的区分）。**在详情里点示例 = 先安装再直接发送**。安装智能体时，它依赖的技能**直接一并装好**，不再弹"将同时安装"确认框（依赖在详情"会用到的技能"里事先可见）；安全扫描或质量检查需要用户确认时，照常弹出现有的风险卡 / 质量报告；依赖被平台停用或客户端版本不够时，提示原因、不安装。不展示百分比或步骤 | 安装无法省略；按钮写"安装"就只安装、不跳走，避免意外；点示例说明用户要用，所以一步到位 |
| R9 | **安装失败**：卡片保留，显示"安装失败，可重试"；详情给出原因和"重试"；不进入任务；不破坏已有内容 | 用户只需要知道"在装、装好了、没装成" |
| R10 | **已安装**：入口在首页工具栏最右，按钮带数量；列出所有装到本机的平台内容（含老用户迁移来的原随包内容和默认安装的内容），每行图标、名称、简介、"卸载"、启用 / 停用开关；页头"已启用 N / 共 M"；为空时说明"点安装后会出现在这里"。主智能体、外接智能体、自建、本机已有的技能不在这里 | 装到本机的平台内容都会被主智能体自动调用，需要一个集中开关、卸载的地方；一样东西只放一处 |
| R11 | **停用的效果**：停用后主智能体在新任务里不再调用它、@ 也找不到它；卡片变暗并标"已停用"，"使用"和示例不可点；仍可点开详情并"启用"。停用对**所有**智能体生效 | — |
| R12 | **停用有依赖**：用户停用一个技能时，如果有智能体会用到它，先提示"智能体 X、Y 会用到它，停用后它们将暂时不能使用"，可取消；确认后停用。受影响的智能体**暂时不能使用**（"使用"和示例不可点，与平台停用依赖时的现有做法一致）：卡片上提示"依赖已停用"，详情"会用到的技能"里把该技能标为"已停用"，底部提供"启用「技能名」"一键恢复 | 否则用户只觉得智能体"莫名变笨"。现有客户端只在平台停用某技能时提示，用户自己停用不提示 |
| R13 | **更新**：已安装的平台内容有新版本时，卡片标"有更新"，详情底部有"更新"；更新失败保留旧版并提示；正在运行的任务不换版本，新任务才用新版 | 新弹窗替代旧的详情页，不能丢掉已有的更新能力 |
| R14 | **我的**："我的智能体"只放自建的；"我的技能"一个网格放自建 + 本机已有，自建在前，卡片标"自定义 / 本机已有"，外部包卡片显示包来源；本机已有的没有"贡献"；顶部有全局文件夹总开关，关闭后这些技能不显示、不被调用，文件本身不动；外部包"移除"前确认，并说明会一并移除它带的技能；"我的贡献"进入客户端现有的贡献页，返回回到"我的" | 首页只放平台给的，自己的东西都在"我的" |
| R15 | **内容缺示例时**：详情显示一条通用示例（"请用 X 帮我处理这项工作"），不留空 | 示例批量补齐前，弹窗不能空着 |

## 6. 平台内容统一走 Hub（2026-10-19 中扬定）

**为什么**：如果同时存在"客户端自带（不用装、不能卸载）"和"Hub 分发（要装、能卸载）"两类，所有功能（已安装页、卸载、更新、统计、断网）都要按两种情况各写一套，分类会越来越乱。

**现状**：客户端安装包里现有 32 个智能体、58 个技能，启动时复制进本机、登记为"已安装"，联网后由 Hub 接管。它们的编号和 Hub 是同一套，本质就是"提前装好的 Hub 内容"。

**本期界面怎么做**：不再区分自带与 Hub。老用户本机已有的原随包内容，一律按"已安装"展示：出现在"已安装"页，可停用、可卸载。界面改动**不依赖** Hub 是否已完成上架。

**迁移任务（与界面分开推进，嘉宇配合）**：

| # | 事项 | 做法 |
|---|---|---|
| 1 | Hub 上补齐 | 新版本发布前，把现有 32 + 58 全部在 Hub 发布、维护好；用脚本核对编号和版本，缺的、旧的先发布；本地先验证 |
| 2 | 老用户升级 | 原有内容原样保留为"已安装"，用户什么都不丢；去掉"安装包新版本覆盖本机""删除后被重新装回"两个旧机制 |
| 3 | 新用户首次打开 | 不再随包预装；必需的几个在 Hub 标为"默认安装"，登录后自动装 |
| 4 | 特殊内容 | 报销智能体的编号是客户端固定认定的，单独确认处理方式；8 个系统内置技能不迁移 |
| 5 | 依赖 | 智能体依赖的技能都要在 Hub 已发布，安装智能体时才能自动补齐 |
| 6 | 发布顺序 | 先 Hub 全部上架并验证，再发客户端 |

## 8. 异常与边界

- **断网 / 平台不可用**：按 R4。
- **加载中**：主智能体、外接智能体、已安装内容先显示，未安装的位置显示骨架屏。
- **空态**：搜索无结果（带"清除筛选"）、"我的"为空（引导创建）、"已安装"为空、平台暂无更多可安装内容，各有说明。
- **安装慢**：技能文件多时按钮保持"安装中…"，不重复点击。
- **安装被拦**：安全扫描拦截、质量检查不通过，沿用现有风险卡与质量报告。
- **重名**：创建时与已有内容重名，提示修改。
- **已下架**：平台已下架但本机已装的保持可用，在"已安装"里标"已下架"。
- **卸载有依赖**：卸载技能时，若有智能体在用它，先提示"智能体 X 在用此技能"，允许继续，该智能体标"缺少依赖"。
- **停用有依赖**：按 R12。
- **外部包被移除**：它带的技能一并消失。

## 10. 完成标准

| 场景 | 必须观察到的结果 |
|---|---|
| 智能体首页 | 三组顺序正确；平台组不标来源，已安装在前；没有"更多"、自建内容、"N 人在用"；工具栏有分类、搜索、"我的智能体 · N""已安装的智能体 · N"，没有"+ 创建""我的贡献" |
| 技能首页 | 只有平台一组；没有自建、本机已有的技能 |
| 详情 | 同一种弹窗；有简介、示例（缺示例时有通用示例）；按 R2 显示操作；不出现内部结构 |
| 安装与使用 | 已安装的点"使用"进入新任务；未安装的点"安装"→"安装中…"→ 变"使用"、不跳转；详情点示例一步安装并发送；智能体的依赖技能自动装好 |
| 安装失败 | 卡片保留、显示"安装失败，可重试"；不进入任务；已有内容不受影响 |
| 已安装 | 列出全部装到本机的平台内容（含迁移来的），每行有卸载和开关；页头计数正确；没有自建、外接、本机已有的技能 |
| 停用 | 停用后新任务中不被调用、@ 不到；卡片变暗；详情可启用；停用被智能体依赖的技能时先提示；受影响的智能体"使用"不可点，启用技能后恢复 |
| 更新 | 有新版本时卡片标"有更新"、详情可更新；失败保留旧版 |
| 我的 | 我的智能体只有自建；我的技能一个网格（自定义 + 本机已有），可按来源筛选；总开关、外部包移除按 R14 工作；"贡献""我的贡献""+ 创建"可用 |
| 创建 | 创建、外接都能走通，校验正确，落点正确 |
| 断网 | 首页提示并可重试；已安装的照常可用 |
| 未登录 | 主智能体、外接、我的、已安装照常；平台组只有已安装的并提示登录；点安装、贡献先提示登录 |
| 双平台 | macOS 与 Windows 上主流程都走通并有记录 |
